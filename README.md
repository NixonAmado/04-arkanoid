# Arkanoid

Juego clasico de Arkanoid hecho en HTML, CSS y JavaScript puro, sin frameworks ni dependencias.

## Como jugar

1. Abre `index.html` en tu navegador (doble clic o `open index.html`).
2. Pulsa cualquier tecla o haz clic para comenzar.
3. Mueve la paleta con el mouse, o con las flechas `←` `→` (tambien `A` / `D`).
4. Rebota la pelota con la paleta para destruir todos los bloques del nivel.
5. Si la pelota cae, pierdes una vida. Al quedarte sin vidas, es Game Over.
6. Completa los 5 niveles para ganar. Al terminar, pulsa cualquier tecla o clic para volver a jugar.

### Controles

| Tecla / accion | Efecto |
|---|---|
| Mouse | Mueve la paleta |
| `←` / `A` | Mueve la paleta a la izquierda |
| `→` / `D` | Mueve la paleta a la derecha |
| `Escape` o `P` | Pausa / reanuda el juego |
| Cualquier tecla / clic | Inicia el juego o reinicia tras ganar |

## Objetivo

Destruye todos los bloques de cada nivel sin dejar caer la pelota. Hay 5 niveles con dificultad creciente (la velocidad de la pelota aumenta por nivel).

## Requisitos

No hay build ni servidor. Solo un navegador moderno.
